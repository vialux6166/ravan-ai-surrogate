WHAT IS IT?
-----------
A world-class graphical user interface that integrates:
  • Ravan quantum simulation framework
  • TRD (Topological Resonance Distillation) AI training
  • Model inference and testing
  • System monitoring and management

All in one professional, easy-to-use application.

KEY FEATURES:
-------------
✓ Modern dark theme interface
✓ 4 integrated tabs (Quantum, Training, Inference, Monitor)
✓ Real-time progress tracking
✓ Background processing (UI never freezes)
✓ One-click operations
✓ Comprehensive error handling
✓ Live training logs
✓ Automatic model detection
✓ GPU monitoring
✓ WSL integration

QUICK START:
------------
1. Install dependencies: install_gui_dependencies.bat
2. Launch GUI: LAUNCH_GUI.bat
3. Navigate tabs to perform operations

MAIN WORKFLOWS:
---------------

Workflow 1: Generate & Train
  1. TRD Training tab → Generate Dataset (1000 examples, ~3 hours)
  2. TRD Training tab → Start Training (3 epochs, ~35 minutes)
  3. Model Inference tab → Test your model

Workflow 2: Run Simulations
  1. Ravan Quantum tab → Select simulation type
  2. Configure parameters
  3. Run simulation

Workflow 3: Query Models
  1. Model Inference tab → Load model
  2. Enter question
  3. Generate response
