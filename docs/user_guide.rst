Overview
--------

This guide covers all aspects of using Ravan, from basic simulations to advanced features like LLM integration and custom model training.

Quick Reference
---------------

Common Tasks
~~~~~~~~~~~~

* **Run a simulation**: Use ``ravan.simulate()``
* **Train a model**: Use ``ravan.train()``
* **Make predictions**: Use ``ravan.predict()``
* **Get explanations**: Use ``ravan.explain()`` (requires LLM)
* **Generate code**: Use ``ravan.generate_code()`` (requires LLM)

See the sections below for detailed information on each topic.
